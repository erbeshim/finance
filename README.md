ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)
Наименование проекта: «ИИ-помощник для контроля личных финансов»
1. Назначение и цели системы
Основная цель системы — автоматизировать и упростить процесс учета личных доходов и расходов пользователя с помощью искусственного интеллекта. Система должна избавить пользователя от необходимости вручную заполнять сложные таблицы или формы, позволяя вести учет через отправку обычных текстовых или голосовых сообщений.
2. Ключевой функционал (Core Features)
Программа разделена на три основных модуля: модуль парсинга (чтения), финансовый движок и аналитический модуль.


2.1. Модуль распознавания информации (Ввод данных)
Система должна уметь принимать данные из сообщений (например, в Telegram-боте или мобильном приложении) и автоматически извлекать из них сумму, тип операции (доход/расход) и суть транзакции.
Текстовые сообщения от пользователя:
Пример: «Купил кофе за 250 рублей» → Расход, 250 руб., категория «Кафе/Рестораны».
Пример: «Пришла зп 50000» → Доход, 50 000 руб., категория «Зарплата».
Банковские SMS и push-уведомления (копипаст):
Система должна распознавать стандартные шаблоны сообщений популярных банков.
Пример: «ECMC7777 15:30 Покупка 1200р Продукты. Баланс: 5400р» → Расход, 1200 руб., категория «Продукты».


2.2. Умное разделение на категории (ИИ-классификатор)
ИИ должен автоматически присваивать транзакции категорию на основе контекста слова. Если категория не определена однозначно, система присваивает ей статус «Разное/Неизвестно» и предлагает пользователю выбрать категорию вручную.
Базовая сетка категорий:
Расходы: Продукты, Кафе и рестораны, Транспорт/Такси, Коммунальные платежи (ЖКХ), Развлечения и отдых, Одежда и шопинг, Здоровье/Аптеки, Разное.
Доходы: Зарплата, Переводы, Инвестиции, Кэшбэк/Бонусы, Прочее.

3. Технологический стек 

• Интерфейс (Frontend): Telegram-бот (самый быстрый и удобный вариант для реализации ввода через сообщения) либо мобильное приложение (Flutter / React Native).
• Серверная часть (Backend): Python (FastAPI / AIOGram) — идеально подходит для работы с ИИ библиотеками.
• База данных: PostgreSQL / SQLite (для хранения транзакций, категорий и профилей пользователей).
• Интеграция ИИ (LLM): OpenAI API (GPT-4o mini) или локальные модели (Llama-3, Mistral) для извлечения сущностей (Субъект, Сумма, Категория) из неструктурированного текста с помощью Structured Outputs (JSON-формат

Запросы по команде: «Сколько я потратил в этом месяце?», «Покажи расходы на такси за неделю».
Регулярные отчеты: автоматическая отправка сводки за неделю/месяц (в текстовом виде или в виде простых графиков).
